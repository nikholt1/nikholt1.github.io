## Introduction

I've been working on a repository inspector that analyzes
GitHub projects and visualizes their structure.

The goal is to make it easier to understand how a project
is organized without having to inspect every file manually.

## Implementation

The inspector uses the GitHub API to retrieve repository
files and analyze their contents.
